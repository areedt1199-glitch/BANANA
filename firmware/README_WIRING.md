### 2. ตารางกำหนดขาพอร์ต ESP32-S3 (GPIO Pinout Allocation)

| ส่วนประกอบ | ฟังก์ชัน / สัญญาณ | ขา ESP32-S3 | หมายเหตุทางวิศวกรรม |
| :--- | :--- | :--- | :--- |
| **I2C Bus** | SDA | `GPIO 8` | ต่อเข้า LCD 2004 (0x27) และ SHT30 (0x44) |
| | SCL | `GPIO 9` | ดึงตัวต้านทาน Pull-up 4.7kΩ ขึ้น 3.3V |
| **RS485 Modbus** | RX (RO) | `GPIO 18` | ต่อโมดูล MAX485 ผ่าน Serial1 |
| | TX (DI) | `GPIO 17` | บัสสื่อสารเซนเซอร์ดิน 7-in-1 (Baud 9600) |
| | DE / RE | `GPIO 10` | ควบคุมทิศทางการส่งข้อมูล Half-Duplex |

| | DC 24V Sense | `GPIO 2` | ผ่านวงจรแบ่งแรงดัน (Voltage Divider 24V -> 3.3V) |

| | ปุ่มโซน 3 | `GPIO 15` | สวิตช์กดติด-ปล่อยดับ |

### 3. ระบบไฟฟ้า 3 ระดับและการวินิจฉัย Fail-safe (Power Architecture)

1. **ระดับที่ 1: ไฟฟ้ากระแสสลับ (AC 220V):**
   - ผ่านเบรกเกอร์กันดูด RCBO และฟิวส์ป้องกัน
   - จ่ายตรงเข้าหม้อแปลงสวิตชิ่ง (Power Supplies) และ Magnetic Contactor ของปั๊มน้ำ
   - มีไฟ Pilot Lamp สีแดง 🔴 `AC 220V` เพื่อตรวจสอบว่าไฟหลวงดับหรือตกหรือไม่
2. **ระดับที่ 2: ไฟฟ้ากระแสตรง (DC 24V 5A):**
   - จ่ายเฉพาะให้กับ **Solenoid Valves ทั้ง 4 โซน** เพื่อให้แรงดึงวาล์วเสถียร ไม่เกิดความร้อนสะสม
   - มีไฟ Pilot Lamp สีเขียว 🟢 `DC 24V` (หากวาล์วไม่เปิดแต่ปั๊มติด ให้มองไฟนี้ก่อนว่าหม้อแปลง 24V พังหรือไม่)
3. **ระดับที่ 3: ไฟฟ้ากระแสตรง (DC 12V -> 5V/3.3V Step-down):**
   - จ่ายให้บอร์ด ESP32-S3 และส่งสัญญาณไฟเลี้ยงให้ **เซนเซอร์ดิน 7-in-1 (RS485)**
   - มีไฟ Pilot Lamp สีเขียว 🟢 `DC 12V` (หากไฟดับ = บอร์ดคอนโทรลเลอร์ไม่ทำงาน)

### 4. การทำงานแบบ Bi-Directional Digital Twin Synchronization

```
[ เกษตรกรกดปุ่มเขียวหน้าตู้ "โซน 1" ]
              │
              ▼
   (ESP32 ตรวจจับ GPIO 6 LOW)
              │
              ├──► 1. สั่ง Relay GPIO 13 Active LOW ──► [โซลินอยด์วาล์ว 24V เปิด] + [ไฟเขียวแถว 6 สว่าง]
              │
              ├──► 2. อัปเดตข้อความบนจอ LCD 2004 แถวที่ 4 ทันที (Z:1)
              │
              └──► 3. ส่ง JSON ผ่าน MQTT Topic "homthong/sync/..."
                            │
                            ▼
              [ Cloud Backend / WebSockets ]
                            │
                            ▼
              [ หน้าจอมือถือ LINE LIFF ของเกษตรกร ]
              (สวิตช์โซน 1 และไฟ LED เสมือน เด้งเปิดแบบ Real-time ภายใน < 0.2 วินาที)
```

และในทางกลับกัน เมื่อเกษตรกรแตะสวิตช์ในมือถือ ระบบจะส่งคำสั่ง MQTT ลงมาให้ ESP32 สั่งรีเลย์และเปิดไฟหน้าตู้พร้อมกันทันที
